# Weather API Testing

## 1. Project Overview & Objectives
This project was completed during my internship with Fortray and involved three testing scenarios: API functional testing, API automation, and performance testing. The objective was to practise API validation, automated testing, and application performance analysis.

## 2. Technologies & Tools
- **Postman** – API testing
- **Java & REST Assured** – API automation
- **Apache JMeter** – Load and performance testing
- **Git & GitHub** – Version control

## 3. Key Features & Functionalities

**Scenario 1: Postman API Testing**
- Created API collections and configured authentication and variables.
- Tested OpenWeather API requests using different location parameters.

**Scenario 2: REST Assured API Automation**
- Implemented GET, PUT, and DELETE requests.
- Practised request execution and response validation using Java.

**Scenario 3: JMeter Performance Testing**
- Created a Test Plan and configured Thread Groups.
- Recorded a sample flight-booking workflow.
- Simulated virtual users and analysed response times and throughput using JMeter reports.

## 4. My Role & Contributions
- Configured and executed API requests using Postman.
- Developed API automation tests using Java and REST Assured.
- Created and executed JMeter load tests.
- Analysed test responses and performance reports.
- Documented testing activities and findings.

## 5. Learning Outcomes
Gained practical experience in API functional testing, Java-based API automation, performance testing, and analysing application behaviour under simulated load.
